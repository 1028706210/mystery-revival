# Codex 数据迁移准备

`Move-CodexData.ps1` 仅迁移当前用户的 `C:\Users\李帅朋\.codex` 到 `D:\CodexData`。它不迁移应用程序本体、不修改系统下载目录、不修改 CODEX_HOME、配置文件、SQLite、全局 JSON 或记忆内容。浏览器下载目录已单独设为 `D:\codex下载`，本脚本不再调整它。

必须先从 Codex 菜单退出应用，关闭相关浏览器和辅助进程，再在独立 PowerShell 窗口执行。脚本检查进程；发现相关进程即停止，绝不强杀。迁移期间不要重新启动 Codex。进程扫描无法消除操作系统级竞态，执行者须确保应用保持关闭。

先做只读检查（检查进程、目标 NTFS、目标不存在以及源目录可完整枚举；不代表文件全部可读或已完成哈希验证）：

```powershell
powershell.exe -NoProfile -File "C:\Users\李帅朋\Documents\ChatGPT\神秘复苏\tools\migration\Move-CodexData.ps1" -CheckOnly
```

实际迁移命令仅供审查后的独立执行；此任务准备阶段没有运行：

```powershell
powershell.exe -NoProfile -File "C:\Users\李帅朋\Documents\ChatGPT\神秘复苏\tools\migration\Move-CodexData.ps1"
```

脚本要求 `D:\CodexData` 尚不存在；不会覆盖之前留下的数据。逐项复制普通目录和文件，复制并验证源访问 ACL，将继承规则固定下来，避免引入 D 盘父目录更宽的权限。文件在写入内容前设置源 ACL；失败即停止。源文件默认数据流和所有备用数据流均逐一进行 SHA256 比对，不打印内容、哈希或认证信息。读取 `auth.json` 仅用于原样复制和哈希，不改写其内容。

不会递归跟随任何重解析点。支持指向源目录内部普通目录的 junction，并将目标改为 D 盘对应目录；当前已观察到 `plugins\cache\openai-bundled\chrome\latest` 指向同目录下 `26.908.40834`。外部链接、符号链接、链接链、循环链接均拒绝迁移，保留原数据供人工检查。

保留文件创建/修改时间和常规文件属性；不承诺保留目录时间、所有者或审计 SACL。源 DACL 会按权限语义核对。EFS 加密文件会拒绝处理，以免在复制时降级保护。

复制及完整哈希验证后，重新检查进程并再次核验，再把 C 盘原目录重命名为独一备份 `.codex.backup-时间-随机后缀`，建立 `.codex -> D:\CodexData` 的 junction。旧配置中硬编码的 C 路径继续通过 junction 访问数据，所以无需改写配置。失败不会自动删除任何数据：切换前失败时原目录保留、D 盘可能有部分副本；建立 junction 失败且原路径不存在时恢复原目录名。目标存在或其他异常需人工检查后再重试。

保留 C 盘备份意味着**暂时不会释放原数据占用的 C 盘空间**。重新启动后验证登录、旧任务记录、浏览器及技能正常，再由用户明确确认是否清理备份；脚本不包含删除功能。完整迁移验证不代表应用启动验证通过。

项目文件应单独完成 C/D 差异核对；本脚本不复制、不覆盖任何项目。项目目标是 `D:\projects\神秘复苏`，完成文件核对后通过 Codex UI 重新打开该目录。`.codex` junction 只兼容旧数据路径，**不会把 C 盘项目工作目录自动改成 D 盘**；旧任务记录保持原样，旧任务可能仍在 C 盘项目操作。

当前准备环境的只读枚举对 `.sandbox-secrets` 与 `video-tools\python` 下部分目录返回 Access denied。必须在关闭应用后的独立终端重新检查；如果仍无法读取全部文件/ACL，脚本会停止，不能忽略这些目录或声明迁移完成。它不主动调整源权限。

`Test-MoveCodexData.ps1` 仅在脚本目录生成随机名的小型测试目录，测试普通文件、备用数据流、内部 junction、ACL 保留、拒绝覆盖目标和拒绝哈希不一致。测试保留该目录，不触及真实 `.codex`。该测试不覆盖真实关闭、目录重命名切换或应用重启。
