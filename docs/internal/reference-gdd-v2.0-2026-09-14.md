# 《神秘复苏》开放世界 2D RPG

# GDD v2.0 制作级总设计文档

版本定位：

v2.0 是从"设计文档"升级到"完整开发基线"。

目标：

让设计、美术、程序、AI Agent 可以基于同一份文档协作开发。

------------------------------------------------------------------------

# 1. 项目核心定位

## 类型

开放世界 2D / 2.5D 灵异 RPG。

平台：

-   Windows
-   Unity
-   C#

------------------------------------------------------------------------

## 核心体验

玩家不是英雄。

玩家是一个进入灵异时代的普通人。

核心循环：

探索 ↓ 发现异常 ↓ 调查 ↓ 记录信息 ↓ 形成推理 ↓ 做出选择 ↓ 承担后果 ↓
改变世界

最高原则：

规则优先于战斗。

------------------------------------------------------------------------

## 第二层：灵异世界

-   鬼域

------------------------------------------------------------------------

## 第三层：历史深层

包括：

-   老一代驭鬼者
-   旧时代事件
-   未完成计划
-   灵异封锁区域

特点：

玩家逐渐发现：

自己面对的事情早已开始。

# 3. 厉鬼系统

## 公开危险评级

总部评级：

C 限制级

B 危险级

A 灾难级

S 毁灭级

评级代表：

社会危害。

不是战斗力。

------------------------------------------------------------------------

## 内部参数

每只鬼拥有：

-   灵异强度
-   规则复杂度
-   扩散能力
-   鬼域能力
-   拼图完整度
-   压制能力
-   智慧程度

------------------------------------------------------------------------

-   媒介

-   杀人方式
-   限制

调查：

-   初始异常

扩展：

# 4. 驭鬼者系统

↓

↓

↓

尝试驾驭

↓

成功 / 失败

失败可能：

-   死亡
-   灵异侵蚀
-   身体变化
-   世界后果

成长来自：

-   驾驭厉鬼
-   理解能力
-   获得拼图
-   灵异平衡
-   经历事件

## 灵异平衡

多个灵异之间：

-   压制
-   冲突
-   互补
-   失衡

强大不代表安全。

# 10. 死亡系统

角色永久死亡。

但是：

世界继续。

新角色可以发现：

-   前角色档案
-   遗留物品
-   安全屋
-   NPC记忆
-   世界变化

死亡成为历史。

# 项目最终原则

1.  鬼不是怪物。
2.  规则比数值重要。
3.  调查比战斗重要。
4.  玩家可以理解规律，但不一定知道真相。
5.  世界不会围绕玩家旋转。
6.  死亡会留下历史。
7.  所有新增内容必须通过世界观审计。
