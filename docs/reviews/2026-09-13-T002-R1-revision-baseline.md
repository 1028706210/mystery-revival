## 一、总体原则（项目负责人原文）

本项目核心目标：

> 制作一个高自由度、规则驱动、具有真实《神秘复苏》氛围的 2D RPG。

设计原则：

- 厉鬼不是普通敌人，而是规则实体。
- 玩家需要通过调查、推理、试错理解规则。
- 不直接展示答案。
- 保持未知感和恐怖感。
- 所有规则必须具备内部逻辑。
- 不允许为了难度强行破坏规则。

## 二、T002-R1 审计修订结果（项目负责人原文）

### P0 必须修改项

#### 01. DoorId 触发去重逻辑

原问题：原设计可能混淆同一次动作重复回调与玩家重新执行同一行为，导致规则触发不一致。

修订方案：采用——

> 仅防止同一次动作重复结算，不限制玩家重新执行行为。

允许：

```
第一次开门 → 触发规则 → 关闭门 → 再次开门 → 视为新的行为
```

禁止：

```
同一次开门事件 → 重复调用10次 → 重复触发10次
```

#### 02. 驭鬼机会定义

原问题：当前设计只描述"获得能力后的使用方式"，没有明确"为什么玩家可以获得能力"。

修订方案：T002 阶段只需要定义：

> 存在一个可调查、可选择、具有风险的驾驭机会。

不在当前事件展开完整驭鬼系统。后续单独设计：驭鬼流程、成功条件、失败结果、灵异侵蚀、死机机制、鬼复苏。

### P1 建议修改项

#### 03. 20秒触发间隔

有效触发条件：

```
错误声明 + 错误行为 + 距离上一次有效触发 >= 20秒
```

目的：避免玩家重复点击刷规则、系统误判；同时保持玩家可以主动实验规则。

#### 04. 空间留痕 / 跨层感知

保留该能力。但是禁止直接告诉玩家：当前真实楼层、正确路线、安全答案。

允许玩家通过空间异常、环境反馈、多个线索自行推理。目标：能力辅助调查，而不是替代调查。

#### 05. 标牌异常表现

允许灵异异常，但避免完全破坏玩家已确认事实。

推荐异常形式：模糊、缺失、被遮挡、不自然变化。谨慎：直接改变核心事实。目标：保持"细思极恐"，而不是"游戏欺骗玩家"。

#### 06. 调查路线补充

路线一需明确：玩家留下什么证据、如何验证、如何形成推理链。路线二需明确：外部参照如何提供线索、玩家如何发现空间异常。

#### 07. 事件动机补充

需要补充玩家为什么进入事件区域：初始目的、调查目标、任务来源、完成条件。避免玩家只是为了触发剧情进入。

### P2 低优先级

#### 08. 非视觉反馈

M0 阶段必须音效反馈、环境声音。后续可加入手柄震动、更复杂反馈。

#### 09. 挂机 / 等待问题

保留当前设计。理由：符合《神秘复苏》风格，玩家选择等待本身也是一种选择。但是异常状态不能简单自动恢复（触发→离开→返回→异常仍存在）。

## 三、后续设计要求（项目负责人原文）

所有后续灵异事件设计必须遵守：

**规则完整性**——每只鬼必须明确：媒介 + 触发条件 + 杀人规律 + 限制条件 + 破解方式 + 错误推理可能 + 隐藏线索。

**恐怖设计方向**——参考中式恐怖、细思极恐、智慧鬼布局、玩家事后回想产生恐惧；避免单纯跳脸、普通怪物战斗、无逻辑死亡。

**开发原则**——设计优先级：1. 规则合理性 2. 玩家推理体验 3. 世界沉浸感 4. 扩展能力 5. 美术表现。
