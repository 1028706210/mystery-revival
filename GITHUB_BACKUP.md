# GitHub Project Snapshot

This private repository stores the current editable Mystery Revival project.

## Contents

- `Game/`: current Unity main project from the D-drive workspace.
- `docs/`, `tests/`, `tools/`: project decisions, task state, checks, and tooling.
- `prototypes/`: the current 2.5D prototype from the C-drive workspace.
- `coordination/`: prototype coordination and handoff documents.

The C-drive prototype and D-drive game are separate working versions. Open the
appropriate Unity project rather than merging their Assets folders.

Editable Blender source models and rendered building previews are backed up in
[blender-works](https://github.com/1028706210/blender-works).

This is a snapshot of current files, not a reconstruction of local Git history.
Unity caches, dependencies, local credentials, logs, and executable builds are
excluded. Existing project documents may contain links to the original local
workspace; use the repository folders above when browsing on GitHub.

The upload does not change development status or claim additional runtime tests.
